# ElderGuard

ElderGuard is a web-based platform designed specifically to help senior citizens identify and avoid online scams occurring through phone calls, text messages, and emails.

## Key Features

ElderGuard was built from the ground up with accessibility in mind. The user interface features a simple, high-contrast design with large, easily clickable buttons.

Upon arriving at the homepage, users are presented with three straightforward options based on their immediate situation:

### 1. Phone Call Guide
* Guides users through a series of simple yes-or-no questions to help them determine if the caller is a scammer.

### 2. Text Message (AI Scan)
* Users can copy and paste suspicious text messages.
* Powered by **Puter.js AI integration**, the app analyzes the text and instantly returns a **danger score** alongside a helpful safety tip.

### 3. E-mail Sender Verification
* Users can input a sender's email address.
* If the domain is a common public domain (e.g., `@gmail.com`, `@yahoo.com`) pretending to represent an official organization, the site flags it and displays a clear warning.
